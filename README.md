# Lean Service: Pulse Care

Creá un sitio web corporativo, moderno, profesional y completamente responsive para LEAN SERVICE, una empresa argentina que brinda soluciones integrales para el cuidado, mantenimiento y funcionamiento de instalaciones empresariales, industriales, institucionales y proyectos vinculados al sector minero.

Voy a adjuntar un archivo ZIP con los logotipos oficiales de Lean. Usá exclusivamente esos archivos como identidad visual y reemplazá cualquier logo generado automáticamente.

1. Identidad de marca

Nombre:

LEAN SERVICE

Slogan oficial:

“LEAN. Cuidamos el pulso de cada espacio.”

Concepto de marca:

Cada espacio tiene su propio ritmo, sus necesidades y una actividad que debe mantenerse en funcionamiento. Lean acompaña ese movimiento mediante servicios integrales de limpieza, fumigación, mantenimiento de espacios verdes y obras civiles.

Frase conceptual:

“Porque cada espacio tiene su propio ritmo, sus propias necesidades y una actividad que no puede detenerse. En Lean trabajamos para que ese pulso se mantenga.”

Frase comercial secundaria:

“Un solo proveedor. Múltiples soluciones.”

No reemplazar el slogan oficial por esta frase.
